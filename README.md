
# Portfolio

A modern, responsive developer portfolio built with Next.js, Tailwind CSS, Framer Motion, and Three.js.

## Features

- ⚡ Blazing fast performance with Next.js
- 🎨 Custom theming with CSS variables and Tailwind CSS
- 🖼️ 3D animated backgrounds using Three.js and @react-three/fiber
- ✨ Smooth page and section transitions with Framer Motion
- 📱 Fully responsive and mobile-friendly
- 🧩 Modular, reusable React components
- 🌙 Dark mode support
- 🛠️ Easy to customize content (projects, skills, testimonials, etc.)

https://portfolio-alpha-orpin-15.vercel.app/

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/portfolio.git
cd portfolio

# Install dependencies
npm install
# or
yarn install
```

### Development

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally.

### Production Build

```bash
npm run build
npm start
```

### Deployment

This project is ready to deploy on [Vercel](https://vercel.com/). Push your code to GitHub and import the repo in Vercel for instant deployment.

## Project Structure

```
src/
	app/           # Next.js app directory
	components/    # Reusable UI and section components
	content/       # Content files (projects, skills, etc.)
	lib/           # Animation and utility logic
	types/         # TypeScript type definitions
public/          # Static assets
```

## Customization

- Update content in `src/content/` (about, projects, skills, etc.)
- Edit theme colors and variables in `globals.css`
- Add or modify sections in `src/components/sections/`

## Technologies Used

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction)
